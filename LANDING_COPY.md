# 6. FAQ

## How accurate are the recommendations?
AudMint uses verified pricing data from official vendor pricing pages and deterministic recommendation logic based on team size, seat counts, and use cases.

---

## Does the tool require login?
No. Users can complete the audit and see results before providing any contact information.

---

## Is my company data public?
No. Public reports exclude identifying information such as company name and email address.

---

## Which AI tools are supported?
Current support includes:
- Cursor
- GitHub Copilot
- Claude
- ChatGPT
- Gemini
- Anthropic API
- OpenAI API
- Windsurf

---

## Is this just an AI-generated recommendation engine?
No. The financial calculations are rule-based and deterministic. AI is only used to generate readable summaries and operational insights.
